Cada sección tiene un título, un tipo y un contenido:
• Texto: un párrafo normal.
• Lista: un ítem por línea.
• Lista numerada (pasos): un paso por línea.
• Grilla de categorías: una categoría por línea, con el formato Título: ítem 1 | ítem 2 | ítem 3
• HTML / Script: pegá código HTML, CSS y JavaScript para mostrar su resultado visual.
• Banner multimedia: agregá una foto, GIF o video mediante un enlace.
